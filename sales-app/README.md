# T-PLANNER 売上集計システム

T-PLANNERからエクスポートしたCSVを取り込み、様々な視点で売上を集計・可視化するWebアプリです。

## 機能

- **CSVアップロード**: T-PLANNERのCSVエクスポートをドラッグ&ドロップでインポート。カラム自動検出＋手動マッピング対応。
- **ダッシュボード**: 売上合計・取引件数・得意先数・月別推移グラフ
- **期間別集計**: 日次/週次/月次/年次で売上を集計・グラフ表示
- **得意先別集計**: 得意先ごとの売上・件数・取引日数。名前で絞り込み可能。
- **商品別集計**: 商品・カテゴリ別の売上。円グラフ＋棒グラフ表示。

## セットアップ

### 必要環境
- Python 3.10 以上

### インストール

```bash
cd sales-app
pip install -r requirements.txt
```

### 起動

```bash
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

ブラウザで `http://サーバーのIPアドレス:8000` にアクセス。

### LAN内の他のPCからアクセスする場合

サーバーのIPアドレスを調べて（例: `192.168.1.10`）、各クライアントのブラウザで `http://192.168.1.10:8000` を開く。

## CSVのカラム形式

アップロード時に自動検出しますが、以下のカラム名に対応しています：

| フィールド | 対応するカラム名の例 |
|-----------|-------------------|
| 売上日 | 売上日, 日付, 受注日, 計上日 |
| 得意先コード | 得意先コード, 顧客コード, 得意先CD |
| 得意先名 | 得意先名, 顧客名, 取引先名 |
| 商品コード | 商品コード, 品番, 商品CD |
| 商品名 | 商品名, 品名, 製品名 |
| カテゴリ | カテゴリ, 分類, 商品分類 |
| 数量 | 数量, qty |
| 単価 | 単価, 販売単価 |
| 金額 | 金額, 売上金額, 受注金額, 合計金額 |

自動検出できない場合は、アップロード画面でカラムを手動でマッピングできます。

## データの保存場所

`sales-app/sales.db`（SQLite）にデータが保存されます。バックアップはこのファイルをコピーしてください。
